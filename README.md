# 🧠 Emotion Detection Using NLP and Machine Learning

## 📌 Project Overview

This project is an NLP-based Emotion Detection web application built using Machine Learning and Streamlit. The model predicts emotions from user text input such as:

* Joy 😄
* Sadness 😢
* Anger 😠
* Fear 😨
* Surprise 😲

The project demonstrates the complete Machine Learning workflow including:

* Data preprocessing
* Text cleaning
* TF-IDF vectorization
* Model training using Logistic Regression
* Emotion prediction
* Interactive Streamlit web application



## 🚀 Features

✅ Detect emotions from user text

✅ Interactive and user-friendly Streamlit UI

✅ NLP preprocessing pipeline

✅ TF-IDF feature extraction

✅ Machine Learning prediction system

✅ Confidence score display

✅ Responsive web application

## ▶️ How to Run the Project

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/snehagulagond/Emotion-Detection-App.git
```

### 2️⃣ Open Project Folder

```bash
cd Emotion-Detection-App
```

### 3️⃣ Install Required Libraries

```bash
pip install -r requirements.txt
```

### 4️⃣ Run Streamlit App

```bash
streamlit run app.py
```



## 📊 Model Information

* Model Used: Logistic Regression
* Feature Extraction: TF-IDF Vectorization
* Problem Type: Multi-class Text Classification
* Approximate Accuracy: 86%

Note: Since the project uses a relatively small dataset, some predictions may not always be perfect.
